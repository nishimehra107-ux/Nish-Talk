## ✨ Features

- Email signup & login system
- Multi-user video calls (create a room, share the Room ID)
- Live room chat and a built-in AI assistant
- Screen sharing, mic / camera controls
- Dark & light theme
- Fully responsive

## 🧰 Tech Stack

HTML · CSS · JavaScript · WebRTC · Supabase

## 🚀 Run

Open `index.html` on any HTTPS host or `localhost` (camera needs a secure origin).
